# झटपट PWA — फोन में इंस्टॉल करने के लिए

यह फ़ोल्डर एक इंस्टॉल-करने-लायक वेब ऐप (PWA) है। इसे फोन में "इंस्टॉल" करने के लिए इसे कहीं
इंटरनेट पर होस्ट करना होगा (क्योंकि फोन का ब्राउज़र इंस्टॉल बटन तभी दिखाता है जब ऐप
https लिंक से खुले, सीधे फाइल से नहीं)।

## सबसे आसान तरीका (5 मिनट, मुफ़्त, कोई कोडिंग नहीं)

1. https://app.netlify.com/drop खोलें (कंप्यूटर पर)
2. इस पूरे फ़ोल्डर (`jhatpat_pwa`) को उस पेज पर खींचकर छोड़ दें (drag & drop)
3. कुछ सेकंड में एक लिंक मिलेगा जैसे `https://xyz123.netlify.app`
4. वही लिंक अपने फोन पर भेजें और Chrome में खोलें
5. नीचे "📲 झटपट इंस्टॉल करें" बटन दिखेगा — उस पर टैप करें
   - या Chrome मेन्यू (⋮) → "Add to Home Screen" / "इंस्टॉल ऐप" चुनें
6. अब झटपट का आइकॉन आपकी होम स्क्रीन पर होगा — बिल्कुल असली ऐप जैसा, बिना किसी APK के

## विकल्प

- **GitHub Pages** — अगर GitHub अकाउंट है तो वहां भी मुफ़्त होस्ट कर सकते हैं
- **Vercel** — netlify जैसा ही मुफ़्त तरीका

## ध्यान रखें

- iPhone पर: Safari में लिंक खोलें → Share बटन → "Add to Home Screen"
- यह अभी भी एक डेमो है (सैंपल डेटा) — असली बैकएंड (लॉगिन, डेटा सेव होना) जोड़ने के लिए
  पहले जो Flutter सोर्स कोड दिया था, वो असली APK ऐप के लिए इस्तेमाल करें
